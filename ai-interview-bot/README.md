# Smart AI Interview Bot

An AI-powered technical interview platform that conducts mock interviews, evaluates answers in real time, adapts difficulty to the candidate's performance, and generates detailed performance reports.

## Features

- **AI-Generated Questions** — Questions are generated by Google Gemini (Gemini 2.0 Flash) based on the job role, technology, experience level, and difficulty you choose.
- **Built-in Question Bank Fallback** — No API key? The app automatically falls back to a built-in question bank and rule-based evaluation, so it works out of the box.
- **Adaptive Difficulty** — Difficulty (beginner → intermediate → advanced) adjusts automatically based on your running average score.
- **Instant Evaluation** — Every answer is scored 0–10 across technical accuracy, depth, communication, and completeness, with strengths, improvements, and detailed feedback.
- **Comprehensive Final Report** — Overall score, technical/communication/problem-solving scores, confidence level, recommended study topics, and a hiring recommendation.
- **Analytics Dashboard** — Track average, latest, and best scores, score trends over time, technology and difficulty breakdowns, and top strengths/improvements.
- **Interview History & Reports** — Review every past interview and its full report.
- **Multiple Interview Types** — Technical, HR/behavioral, or mixed.

## Setup Instructions

### Prerequisites
- Node.js (v16+)
- MongoDB (running locally or MongoDB Atlas)
- (Optional) Google Gemini API key from [Google AI Studio](https://aistudio.google.com/) — skip to use the built-in question bank

### 1. Clone and configure
```bash
cd ai-interview-bot
copy .env.example backend\.env
```
Edit `backend/.env`:
```
MONGODB_URI=mongodb://localhost:27017/ai-interview-bot
JWT_SECRET=your_jwt_secret_here
JWT_EXPIRE=7d
GEMINI_API_KEY=your_gemini_api_key_here
PORT=5000
NODE_ENV=development
FRONTEND_URL=http://localhost:5173
```

### 2. Install backend dependencies
```bash
cd backend
npm install
```

### 3. Install frontend dependencies
```bash
cd ../frontend
npm install
```

### 4. Start MongoDB
```bash
mongod
```

### 5. Start the backend
```bash
cd backend
npm run dev          # or: npm start
```

### 6. Start the frontend
```bash
cd frontend
npm run dev          # or: npx vite --port 5173
```

The app runs at:
- Frontend: http://localhost:5173
- Backend API: http://localhost:5000

### One-click startup (Windows)
Run `start-all.bat` from the `ai-interview-bot` folder. Note: the `.bat` files currently reference the hardcoded path `D:\AI Interview Project` — update them to your actual project location if needed.

## API Endpoints

### Auth
- `POST /api/auth/register` — Register (name, email, password)
- `POST /api/auth/login` — Login
- `GET /api/auth/me` — Get current profile
- `PUT /api/auth/profile` — Update profile (jobRole, technology, experienceLevel)

### Interviews
- `POST /api/interviews` — Create interview (jobRole, technology, experienceLevel, difficulty, totalQuestions, interviewType)
- `GET /api/interviews/history` — Interview history
- `GET /api/interviews/:id` — Get interview details
- `GET /api/interviews/:id/question` — Get the first/next question
- `POST /api/interviews/:id/answer` — Submit an answer (returns evaluation + next question)
- `POST /api/interviews/:id/complete` — Complete interview and generate final report

### Reports
- `GET /api/reports` — All completed reports
- `GET /api/reports/:id` — Single report

### Dashboard
- `GET /api/dashboard/stats` — Aggregated performance stats

### Health
- `GET /api/health` — Server health check

## How It Works

1. **Register / login** to get a JWT.
2. **Configure an interview** — pick a job role, technology, experience level, difficulty, number of questions (1–50), and interview type.
3. **Answer questions** — each question is generated (or pulled from the question bank) and every answer is evaluated immediately on a 0–10 scale.
4. **Adaptive difficulty** — score ≥ 7.5 avg moves difficulty up; < 5 avg moves it down.
5. **Get your report** — a full performance report with a hiring recommendation, then review it anytime from the Reports page.
